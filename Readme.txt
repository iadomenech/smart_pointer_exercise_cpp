This is an exercise proposed for the Computational Physics course (C++), aimed at understanding the mechanics behind std::unique_ptr. The exercise focuses on the use of templates to build a class that manages two types of pointers: pointers to a float value, and pointers to a std::vector<std::string>. Special attention is given to memory management, disabling the copy operator, and implementing move semantics via the move assignment operator (std::move).
The solution is designed to run on Linux systems. Inside the corresponding directory, there is a Makefile provided to compile and execute the code. This Makefile is generic and will work for any program whose name starts with -x-. Technical note: the -g flag is important for using Valgrind, as it provides more detailed information
